# Cybersecurity Learning Journey

Hands-on cybersecurity portfolio focused on **TryHackMe**, selected practical labs, and the skills I am building toward an entry-level **SOC Analyst** role.

The repository is organized by security topic so a recruiter can quickly see what I have studied, what I have practiced, and how the different areas connect.

## Current Focus

**TryHackMe — Cyber Security 101**

All main sections are completed through defensive-security tooling. The remaining block is **OWASP Top 10**.

Completed areas include Linux, Windows and Active Directory fundamentals, command line, networking, cryptography, exploitation, web security, offensive security tooling, defensive security fundamentals, security solutions, and defensive analysis tooling.

After Cyber Security 101, the next major path will be **TryHackMe SOC Level 1**, with selected SOC investigations promoted to portfolio labs.

## Portfolio Labs

### Lab 01 — Basic Network Traffic Analysis
Hands-on packet and protocol analysis with Wireshark and tcpdump, including ICMP, DNS, HTTP/HTTPS, TCP handshakes, addressing, routing, and neighbor discovery.

[Open Lab 01](01-networking/basic-network-traffic-analysis/)

### Lab 02 — Cryptography and Password Security
Hands-on work with SHA-256 integrity checks, Hashcat, salted password hashes, AES encryption, RSA public-key cryptography, and digital signatures.

[Open Lab 02](02-cryptography/cryptography-and-password-security/)

### Planned Lab 03 — Web Application Security Assessment
A selected portfolio lab combining web fundamentals, Burp Suite, offensive web tooling, and OWASP concepts in an authorized lab environment.

## Repository Philosophy

This is not a collection of copied TryHackMe walkthroughs.

I document selected exercises that demonstrate practical skills, troubleshooting, tool usage, investigation, and security concepts. A full portfolio lab is created only when the exercise adds clear practical value.

Detailed system-administration work is kept in my separate **IT Systems Administration Labs** repository to avoid duplication.

## Learning Direction

**Cyber Security 101 → SOC Level 1 → SOC Analyst / Incident Response skills**
