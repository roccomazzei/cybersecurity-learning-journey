## Documentation Style

Each entry should focus on understanding and practical application rather than reproducing room answers.

Recommended structure:

1. Objective
2. Concepts learned
3. Tools and commands
4. Practical work
5. Evidence
6. Key takeaways
7. SOC / defensive-security relevance

Use the repository [THM lab template](../templates/thm-lab-template.md) when creating a new entry.
