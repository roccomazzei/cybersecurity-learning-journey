> Dedicated SOC Analyst learning path focused on monitoring, triage, investigation, detection, and incident handling.

## 🎯 What This Path Builds

- SOC operations and analyst workflows
- Alert triage and reporting
- SIEM, EDR and SOAR fundamentals
- Phishing investigation
- Network and web security monitoring
- Windows and Linux threat detection
- Malware concepts for SOC analysts
- Threat intelligence and IOC enrichment
- Incident investigation and escalation

## 🧠 Investigation Mindset

```text
Alert
  ↓
Validate & Triage
  ↓
Gather Evidence
  ↓
Correlate Events
  ↓
Enrich IOCs
  ↓
Build Timeline
  ↓
Verdict / Severity
  ↓
Escalate or Close
```

## 🧪 Portfolio Direction

Selected rooms and challenges will become **larger SOC investigation labs** only when they demonstrate clear practical value.

Potential portfolio themes include:

- SIEM alert triage and investigation
- Phishing investigation
- Windows / Linux threat detection
- Network security monitoring
- End-to-end incident investigation

> [!IMPORTANT]
> The goal is **not one lab per section**. This path will produce a small number of stronger investigations that demonstrate triage, evidence analysis, correlation, IOC enrichment, decision-making, and reporting.
