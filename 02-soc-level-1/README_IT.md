```text
  ↓

  ↓

  ↓
Correlate Events
  ↓
Enrich IOCs
  ↓

  ↓
Verdict / Severity
  ↓
Escalate or Close
```

## 🧪 Direzione del portfolio

Solo room e challenge con reale valore da SOC Analyst verranno trasformate in **lab di investigation più ampi**.

Possibili temi:

- SIEM alert triage e investigation
- phishing investigation
- Windows / Linux threat detection
- network security monitoring
- incident investigation end-to-end

> [!IMPORTANT]
> L'obiettivo **non è un lab per ogni sezione**. Il percorso produrrà pochi casi più forti che dimostrino triage, analisi delle evidenze, correlazione, IOC enrichment, decision-making e reporting.
